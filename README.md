# 先人たちの遺言 — 言葉の文庫

537人・722作品／発言単位の辞世・遺言・愛誦句を読む静的ウェブサイト。

## 機能

年代（没年基準）、作品形式、死生観テーマ、人物名・本文の複合検索。栞の保存、並び替え、カード／一覧、ランダム閲覧、三人比較。個別ページに出典・史料上の注意、読み、縦書き、文字サイズ、共有、印刷を用意。

個人情報の収集・広告・アクセス解析はなし。栞などはブラウザのlocalStorageにのみ保存。Google Fontsを使用。

## 公開

GitHub Pagesでmainブランチのルートを公開。`.nojekyll`で静的ファイルを直接配信。

## 画像と資料

画像は `credits.html` と `data/images.json` に提供元・利用条件を記載。国立国会図書館「近代日本人の肖像」の保護期間満了画像とMet Open AccessのPublic Domain画像を使用。自筆書、肖像、追善版画、装飾を区別して表示。

史料の出典・異説・未対校の留保は個別人物ページを参照。本文の作品数には異文を別単位にした例がある。内容や第三者画像に、サイトのコードと一律のライセンスを適用しない。

## ローカル確認

```sh
python3 -m http.server 8765
npm ci
node check-site.cjs
```

HTMLは正本の研究データから生成したスナップショット。検索用の `data/catalog.json` は全537人を収録する。
